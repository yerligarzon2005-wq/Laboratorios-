# Laboratorio 03 — Programación Orientada a Objetos en Java

Este proyecto contiene la solución completa del **Laboratorio 03**, enfocado en los fundamentos de la **Programación Orientada a Objetos (POO)** en Java. Se abordan conceptos clave como clases, objetos, atributos, métodos, constructores, uso de la referencia `this`, encapsulamiento, modificadores de acceso (`private` y `public`), reglas de negocio y separación de responsabilidades.
